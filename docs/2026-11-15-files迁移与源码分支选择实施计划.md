# files/ 迁移与源码分支选择 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把固件 overlay 的所有权移交给 ponwrt 源码树，并让固件工作流能在运行时选源码分支、按分支隔离缓存。

**Architecture:** 编译仓库不再持有 `files/`，那行 `mv files openwrt/files` 直接删除（不是改成 cp）。分支通过 `workflow_dispatch` 的 choice 输入进入工作流级 `env.REPO_BRANCH`，再插入两个工作流的 cache key / restore-keys / Clear 前缀。发布工作流不加分支输入，但缓存站点同步加分支段以保住「共用缓存」不变式。

**Tech Stack:** GitHub Actions、POSIX sh、git（多分支 blob 同步）、Python（yaml 解析与不变式校验）

**依据文档:** `docs/2026-11-15-files迁移与源码分支选择设计.md`（ rationale 与证据都在那里，本计划只给可执行步骤）

**范围:** 本计划只覆盖设计文档的 A/B/D/E/F/G 节。C 节（两个 PON feed fork + bugfix 钉 sha + 删补丁与脚本）被「用户建 fork 并给出 40 位 sha」阻塞，fork 就绪后另写计划。

**通用约束:**
- 命令一律单行，禁反斜杠续行。
- 提交信息中文。**全程不 push**，推送由用户执行，且 ponwrt 与编译仓库必须成对推（设计文档第九节）。
- 临时脚本与产物放 `tmp/`（已 gitignore）。
- 改 Linux 侧读取的文件后必须核 blob 行尾：`git ls-files --eol` 要 `i/lf`，CR 字节数用 `tr -dc '\r' < 文件 | wc -c` 数，不认 `git add` 的 CRLF 警告。
- 仓库路径：编译仓库 `D:/WorkSpace/ImmortalWrt-firmware-build`，源码仓库 `D:/WorkSpace/PonWrt`。

```python
import os, re, subprocess, sys, yaml

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
FW = ".github/workflows/build-an7581-immortalwrt.yml"
PUB = ".github/workflows/publish-feed-repos.yml"
BR = "${{ env.REPO_BRANCH }}"
fails = []


def check(name, ok, detail=""):
    print(("PASS " if ok else "FAIL ") + name + (("  | " + detail) if detail else ""))
    if not ok:
        fails.append(name)


def load(rel):
    with open(os.path.join(ROOT, rel), encoding="utf-8") as f:
        return yaml.safe_load(f)


def git(*args):
    return subprocess.run(["git", "-C", ROOT] + list(args), capture_output=True, text=True).stdout.strip()


def dispatch(d):
    # PyYAML 按 YAML 1.1 把 on: 解析成布尔 True，实测两个工作流顶层键都是 True
    return d[True]["workflow_dispatch"]


fw, pub = load(FW), load(PUB)
fwraw = open(os.path.join(ROOT, FW), encoding="utf-8").read()
pubraw = open(os.path.join(ROOT, PUB), encoding="utf-8").read()

# 1. 分支输入
inp = dispatch(fw)["inputs"].get("repo_branch")
check("inputs.repo_branch 存在", inp is not None)
if inp:
    check("repo_branch 是 choice", inp.get("type") == "choice", str(inp.get("type")))
    check("options 恰为 [master, bugfix]", inp.get("options") == ["master", "bugfix"], str(inp.get("options")))
    check("default 为 master", inp.get("default") == "master", str(inp.get("default")))

# 2. env 一处声明
check("REPO_BRANCH 由 inputs 求值", fw["env"]["REPO_BRANCH"] == "${{ inputs.repo_branch || 'master' }}", fw["env"]["REPO_BRANCH"])
check("发布侧 REPO_BRANCH 仍是静态 master", pub["env"]["REPO_BRANCH"] == "master", pub["env"]["REPO_BRANCH"])
check("发布侧没有 repo_branch 输入", "repo_branch" not in dispatch(pub)["inputs"])

# 3. 缓存站点全部带分支段
for label, raw in (("固件", fwraw), ("发布", pubraw)):
    for layer in ("dl", "ccache"):
        old = "env.CONFIG_NAME }}-%s-" % layer
        new = "env.CONFIG_NAME }}-%s-%s-" % (BR, layer)
        check("%s工作流 %s 无旧前缀残留" % (label, layer), raw.count(old) == 0, "残留 %d" % raw.count(old))
        check("%s工作流 %s 新前缀 5 处" % (label, layer), raw.count(new) == 5, "实际 %d" % raw.count(new))

# 4. 共用缓存不变式：把分支段代入 master 后两个工作流的 key 逐字符相同
def keys(raw):
    return re.findall(r"key: (\$\{\{ env\.CONFIG_NAME \}\}[^\n]*)", raw)


fk = [k.replace(BR, "master") for k in keys(fwraw)]
pk = [k.replace(BR, "master") for k in keys(pubraw)]
check("master 下两个工作流 key 相同", fk == pk and len(fk) == 2, "固件=%s 发布=%s" % (fk, pk))

# 5. overlay 所有权已移交
check("固件工作流不再有 mv files", "mv files" not in fwraw)
check("编译仓库不再跟踪 files/", git("ls-files", "files/") == "", git("ls-files", "files/"))

# 6. release 门控与溯源
rel = fw["jobs"]["release"]
check("release 门控到 master", "env.REPO_BRANCH == 'master'" in rel["if"], rel["if"])
check("build 输出 src_sha", "src_sha" in fw["jobs"]["build"]["outputs"], str(fw["jobs"]["build"]["outputs"]))
check("克隆步骤输出 src_sha", "src_sha" in fwraw)

# 7. .gitattributes 两条死规则已删
ga = open(os.path.join(ROOT, ".gitattributes"), encoding="utf-8").read()
check(".gitattributes 无 files/** 规则", "files/**" not in ga)
check(".gitattributes 无 *.init 规则", not re.search(r"^\*\.init ", ga, re.M))

print("\n%d 项失败" % len(fails))
sys.exit(1 if fails else 0)
```

## Task 6: 两个工作流 — 缓存按分支隔离

20 个站点（每文件 dl 5 处 + ccache 5 处）是同一字面量的机械替换，用带断言的脚本做，比 20 次手工 Edit 更可核。

**Files:**
- Create: `tmp/retarget-cache-keys.py`
- Modify: `.github/workflows/build-an7581-immortalwrt.yml`、`.github/workflows/publish-feed-repos.yml`

- [ ] **Step 1: 写替换脚本**

写入 `tmp/retarget-cache-keys.py`：

```python
import sys

FILES = [".github/workflows/build-an7581-immortalwrt.yml", ".github/workflows/publish-feed-repos.yml"]
PAIRS = [("env.CONFIG_NAME }}-dl-", "env.CONFIG_NAME }}-${{ env.REPO_BRANCH }}-dl-"), ("env.CONFIG_NAME }}-ccache-", "env.CONFIG_NAME }}-${{ env.REPO_BRANCH }}-ccache-")]
APPLY = "--apply" in sys.argv

for path in FILES:
    with open(path, encoding="utf-8", newline="") as f:
        raw = f.read()
    cr = raw.count("\r")
    out = raw
    for old, new in PAIRS:
        n = out.count(old)
        assert n == 5, "%s: %s 期望 5 处，实际 %d" % (path, old, n)
        assert out.count(new) == 0, "%s: %s 已存在，脚本不幂等，停下" % (path, new)
        out = out.replace(old, new)
    assert out.count("\r") == cr, "%s: CR 字节数变了" % path
    assert len(out) - len(raw) == 2 * 5 * len("${{ env.REPO_BRANCH }}-"), "%s: 增量长度不符" % path
    print("%s: dl 5 处 + ccache 5 处 -> 带分支段，CR=%d，字节 %d -> %d" % (path, cr, len(raw), len(out)))
    if APPLY:
        with open(path, "w", encoding="utf-8", newline="") as f:
            f.write(out)
print("已写盘" if APPLY else "预览（未写盘），加 --apply 才写")
```

- [ ] **Step 2: 先预览，核对计数**

Run: `py tmp/retarget-cache-keys.py`
Expected: 两行各报 `dl 5 处 + ccache 5 处`，末行 `预览（未写盘）`。任何 assert 失败都停下排查，不要改断言。
实测：固件工作流 CR=0（17323→17553 字节），发布工作流 **CR=318**（12576→12806）。
发布侧工作区是 CRLF（`core.autocrlf=true` checkout 所致，`w/crlf`），但**两个 blob 都是 LF**
（`git cat-file blob HEAD:… | tr -dc '\r' | wc -c` 均为 0），入库归一后仍 LF，不影响 Actions。
脚本按设计保留工作区原字节，不顺手改行尾（避免混入无关 diff）；提交后须复核 blob CR=0。

- [ ] **Step 3: 写盘**

Run: `py tmp/retarget-cache-keys.py --apply`
Expected: 同样两行 + `已写盘`。
